JavaScript Promise Methods – Practice

Q1 – Promise.resolve
Promise.resolve(Promise.resolve("DONE"))
  .then(res => console.log(res));

👉 Question: What will be printed and why?

Q2 – Promise.reject
Promise.reject("ERROR")
  .then(() => console.log("A"))
  .catch(err => console.log(err));

👉 Question: Will "A" print? What is the output?

Q3 – Promise.all
Promise.all([
  Promise.resolve("A"),
  Promise.reject("B"),
  Promise.resolve("C")
])
.then(res => console.log(res))
.catch(err => console.log(err));

👉 Question: What will be printed? Why?

Q4 – Promise.allSettled
Promise.allSettled([
  Promise.resolve("A"),
  Promise.reject("B")
])
.then(res => console.log(res));

👉 Question: How many items are in the result? What does each item contain?

Q5 – Promise.race
Promise.race([
  new Promise(res => setTimeout(() => res("A"), 100)),
  new Promise(res => setTimeout(() => res("B"), 50))
])
.then(res => console.log(res));

👉 Question: What will be printed and why?

Q6 – Promise.any
Promise.any([
  Promise.reject("X"),
  Promise.resolve("Y"),
  Promise.resolve("Z")
])
.then(res => console.log(res))
.catch(err => console.log(err));

👉 Question: What will be printed? Why is "X" ignored?
